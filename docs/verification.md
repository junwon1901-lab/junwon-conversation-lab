`python -m pytest tests -q`: 54개 테스트 통과 기록은 `test_results.txt`에 있다. 실제 모델의 문장 품질과 모의 객체를 사용하는 라우팅 테스트는 구분한다. 네트워크 차단, 계산값, 세션 격리, 검색 실패 안내, 출처 없는 인용번호 제거, UI 입력과 그래프를 검사한다.

`python scripts/verify_analysis.py`로 기본 공개 데이터와 직접 입력한 6점 예시의 실제 결과를 `numeric_results.json`에 저장했다. 기본 데이터에서 검증 RMSE로 선택한 모델은 신경망이며 테스트 RMSE는 14.1035다. 작은 예시의 선형 예측은 x=10에서 23이다.

## 공개 사이트 관찰

- Python 3.12.16 환경으로 배포 완료. Plotly import 성공.
- 인터넷 OFF 상태에서 직접 입력한 6개 점으로 선형회귀, 3개 모델 비교, x=10 예측값 23을 확인했다.
- 신경망 구조와 손실 곡선이 표시되었다.
- Qwen3가 발표 준비에 관한 일반 질문에 세 가지 제안을 생성했다. 표현과 내용의 정교함에는 한계가 있다.
- 채팅 가이드를 공식 st.bottom 영역에 고정했다. 분석 실행 버튼과 표의 도구 버튼은 제거했다.
- 배포 중 의존성 갱신 때 일시적인 모듈 reload 오류가 로그에 나타났으며 서버 재시작 후 정상 화면과 대화를 확인했다.
- 무료 서버 절전 후 깨우기와 재접속을 확인했다.

기기의 네트워크를 물리적으로 끊은 브라우저 접근은 지원 대상이 아니다. OFF는 앱의 외부 요청 정책이며 완전한 통신 단절에서는 사전 설치된 PC 로컬 실행이 필요하다. 모든 가능한 질문·브라우저·동시 사용자 부하를 검사한 것은 아니다.

- 2026-11-18 공개 앱 웹 검색: 부력 질문에 자료 3개, 본문 일부 2개·검색 요약 1개, 시각과 링크 표시를 확인했다. 생성 답변의 정적 평형 설명에는 오류가 있어 보고서에 정확한 조건과 한계를 명시했다.

후속 질문에서 검색 실패 안내와 대화 지속을 확인했다. 후속 답변에도 부력 평형 설명 오류가 남았다. 공개 모델의 사실 정확성 개선은 남은 한계이며, 실행 테스트 통과를 모든 답변의 정확성으로 주장하지 않는다.
