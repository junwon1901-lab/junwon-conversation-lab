# 확인된 오류 보완 및 재검증

## 변경 사항

- 실행 결과의 외삽 여부와 모순되는 LLM 설명을 검사한다. x=10은 학습 범위 1~6 밖이라는 Python 판정을 유지한다. 실제 정답 없이 예측 오차를 확정하지 않는다.
- 작은 데이터에서 R²=1 또는 반올림 RMSE=0을 완벽한 정확도로 일반화하는 표현을 검사한다.
- 부력 자료를 참고한 응답에서 잠긴 체적과 무관하다는 설명, 정지 평형에서 부력이 무게보다 커야 한다는 설명을 검사한다.
- 충돌을 검출하면 규칙 기반 설명으로 대체했다고 표시한다. 이것을 LLM 자체 성능 향상이나 가중치 학습으로 부르지 않는다. 모든 사실 오류를 판별하는 검증기는 아니다.
- 추가 검사에서 발견한 출처 번호 고정 문제를 수정했다. 참고 자료의 실제 위치에 맞춰 인용한다.
- 모델 저장소와 공개 웹을 각각 점검한다. 점검 실패를 인터넷 전체 단절로 단정하지 않고, 실제 검색의 성공·실패와 별도로 표시한다.

## 온라인 확인

이번 실행 환경에서는 두 점검 URL이 시간 초과됐지만 실제 검색은 성공하여 Wikipedia, Britannica, Physics LibreTexts의 부력 자료 3개를 반환했다. 따라서 점검 서버 응답 여부만으로 전체 인터넷 연결 여부를 단정할 수 없다. 검색 제공자의 일시적인 실패까지 없앨 수는 없으며 실패 시 확인하지 않은 최신 정보를 검색했다고 표시하지 않는다.

## 검증 구분

자동 테스트는 계산·OFF 차단·화면 구성·문서·기억·설명 교정 규칙을 검사한다. 실제 모델 재시험은 별도의 JSON 기록에 남긴다. 기존 실험 기록은 이전 상태의 기록으로 보존한다. 이전 1·2차 과제는 변경하지 않는다.

검증 결과: 자동 테스트 72개 통과. 실제 Qwen으로 8회 입력 흐름(자료 등록·자연어 분석·예측·부력 질문·문서 등록·문서 질문·기억 저장·기억 질문)을 완료했다. 전장 42미터·담수 조건과 발표 주제 선체 저항을 다시 답했다. 재실행 기록: `docs/nov22_llm_results.json`.
